# Inicio

Mapa de la bóveda. Abre la carpeta `docs/` como bóveda en Obsidian para ver el grafo.

- [[Arquitectura]]: cómo se conectan interfaz y backend.
- [[Rueda]]: interfaz radial de formatos (`src/`).
- [[Conversores]]: lógica de conversión en Rust (`src-tauri/src/`).
- [[Comandos-Tauri]]: funciones de Rust que llama el JS.
- [[Herramientas]]: la segunda rueda (comprimir, recortar, metadatos, girar...).
- [[Nautilus]]: clic derecho y cómo compilar el binario independiente.
- [[Decisiones]]: por qué se eligió cada cosa.
- [[Referencia-Tangerine]]: cómo funciona la app de Mac que nos inspira.
- [[Configuracion]]: formatos que muestra la rueda, elegidos por el usuario.
- [[Idiomas]]: inglés por defecto y español, cómo se elige y qué se traduce.
- [[Publicar]]: empaquetado, .deb y pendientes antes de publicar en GitHub.
